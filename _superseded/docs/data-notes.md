# 데이터셋 주의사항

이 문서는 참조용이다. 데이터 로딩·전처리·분할 코드를 작성하거나 수정하기 전에 읽는다.
EXP-001(무결성 점검)의 근거 문서이기도 하다.

---

## 1. 왜 이 문서가 필요한가

CIC-IDS2017은 IDS 연구에서 가장 널리 쓰이는 벤치마크지만, 후속 연구들이
데이터 생성 파이프라인 전반에서 결함을 보고했다. 이 프로젝트의 핵심 지표인
**보정 후 신뢰도 분포**는 데이터 결함에 직접 영향을 받는다.
누수 특징이 남아 있으면 모델이 과도하게 확신하게 되고, 유보 구간이 거의 비어
RQ1의 측정 자체가 불가능해진다. 따라서 데이터 검증이 모든 실험의 선행 조건이다.

## 2. 알려진 결함

### 2.1 라벨 오류
- 실제로 수행되었으나 공격으로 라벨링되지 않은 트래픽이 존재한다.
- 포트 스캔 계열의 라벨이 잘못 부여된 사례가 보고됐다.

### 2.2 플로우 구성 및 특징 추출 결함
- 특징 추출 도구(CICFlowMeter) 자체의 버그로 CSV가 잘못 생성된 부분이 있다.
- 패킷 순서 뒤바뀜(misordering), 패킷 중복, 문서화되지 않은 캡처 공백이 보고됐다.
- 식별 특성이 전혀 없는 무의미한 아티팩트 플로우가 상당 비율을 차지하며,
  일부 공격 범주에서는 그 비율이 특히 높다.

### 2.3 누수(leakage) 가능성이 있는 특징
아래는 학습에서 제외 여부를 반드시 검토한다. 자동으로 지우지 말고 EXP-001에서
기여도를 측정한 뒤 사용자에게 보고한다.
- `Destination Port` — 공격별 포트가 고정되어 사실상 라벨 대리 변수가 된다.
- `Flow ID`, `Source IP`, `Destination IP`, `Timestamp` — 레코드 식별자 역할.
- 공격 시나리오가 시간대별로 분리 수행되었으므로, 시간 관련 특징 전반이 위험하다.

### 2.4 후속 데이터셋도 동일 문제
CIC-CSE-IDS2018에서도 같은 문제가 확인됐다. 데이터셋을 바꾸는 것으로는 해결되지 않는다.

## 3. 대응 방침

1. **정제된 버전을 사용한다.** 원본 CSV를 그대로 쓰지 않는다.
   PCAP에서 재추출한 교정 데이터셋(LYCOS-IDS2017 등)이나 재라벨링된 공개 버전을 우선 검토한다.
2. **어떤 버전을 썼는지 `metrics.json`의 `dataset` 필드에 정확히 기록한다.**
   "cicids2017"만으로는 부족하다. 출처와 버전을 명시한다.
3. **중복 플로우를 제거한 뒤 분할한다.** 중복이 학습·평가에 걸쳐 있으면 성능이 부풀려진다.
4. **분할은 파일(요일) 단위가 아니라 시간 순서를 고려해 수행한다.**
   무작위 분할은 동일 공격 세션의 플로우를 학습·평가에 나눠 넣어 누수를 만든다.
5. **클래스 불균형을 확인하고 기록한다.** 정확도가 아니라 FPR·FNR 기준으로 평가한다.
6. **원본 파일의 SHA256을 기록한다.** `data/`는 git에 넣지 않으므로 체크섬이 유일한 재현 근거다.

## 4. EXP-001에서 반드시 산출할 것

- 전체 플로우 수, 라벨 분포, 공격 유형별 분포
- 결측치(NaN)와 음수값이 나타나는 컬럼 목록 및 비율
- 완전 중복 행의 비율
- 누수 후보 특징을 제거했을 때와 유지했을 때의 성능 차이
- 누수 후보 제거 후 신뢰도 분포가 유보 구간에 들어오는지 여부

마지막 항목이 EXP-003의 사전 신호다. 여기서 이미 분포가 0과 1에 극단적으로 몰려 있다면
데이터 정제를 더 진행한 뒤 EXP-002로 넘어간다.

## 5. 참고 문헌

인용 시 원문을 직접 확인할 것. 아래는 서지사항이 확인된 항목이다.

- Sharafaldin et al. (2018). CIC-IDS2017 원 데이터셋 논문.
- Engelen et al. (2021). *Troubleshooting an Intrusion Detection Dataset: the CICIDS2017 Case Study.*
  IEEE Security and Privacy Workshops (SPW), pp. 7–12.
  트래픽 생성·플로우 구성·특징 추출·라벨링 전반의 문제를 지적하고 개선된 처리 방법론을 적용,
  원본 트래픽의 20% 이상을 재구성하거나 재라벨링했다.
- Lanvin et al. (2023). *Errors in the CICIDS2017 Dataset and the Significant Differences in
  Detection Performances It Makes.* CRiSIS 2022, LNCS, Springer, pp. 18–33.
  라벨링 오류와 패킷 순서 뒤바뀜·중복을 지적하고 교정의 영향을 평가했다.
- Rosay et al. (2022). LYCOS-IDS2017 / LycoSTand. ICISSP 2022.
  CICFlowMeter의 결함을 분석하고 PCAP에서 재추출한 교정 데이터셋을 오픈소스로 공개했다.

**주의**: 논문 인용 시 arXiv 번호, 게재지, 연도를 반드시 원문에서 재확인한다.
검증되지 않은 인용은 이 프로젝트의 이전 검토에서 리스크로 지적된 항목이다.
