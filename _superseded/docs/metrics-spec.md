# 지표 정의 및 계산 규약

이 문서는 지시문이다. 평가 코드를 작성할 때 아래 정의를 그대로 구현한다.
정의가 애매한 지표를 임의로 해석해 구현하지 않는다.

---

## 1. 공통 규약

- 모든 지표는 **보정 후 확률**을 입력으로 계산한다. 보정 전 값으로 계산해야 하는 경우
  `_raw` 접미사를 붙여 별도 필드로 기록한다.
- 양성 클래스(positive)는 **공격**이다.
- 정확도(accuracy)는 산출하지 않는다. 클래스 불균형으로 인해 해석 가치가 없다.
- 모든 지표는 평가 세트에서만 계산한다. 학습·보정에 쓴 데이터로 계산하지 않는다.

## 2. 분류 지표

| 필드 | 정의 |
|---|---|
| `fpr` | 정상 플로우 중 공격으로 판정된 비율 (오탐률) |
| `fnr` | 공격 플로우 중 정상으로 판정된 비율 (미탐률) |
| `precision` | 공격 판정 중 실제 공격의 비율 |
| `recall` | `1 - fnr` |
| `auprc` | Precision-Recall 곡선 아래 면적. 불균형 데이터의 주 요약 지표 |

- ROC-AUC는 보조로만 기록한다. 불균형이 심하면 낙관적으로 나온다.
- **유보된 플로우는 이 지표들의 분모에서 제외한다.** 1차 모델이 판정한 것만 대상이다.
  유보를 포함해 계산하면 유보 비율을 늘리는 것만으로 지표가 좋아지는 착시가 생긴다.
  유보를 포함한 전체 시스템 성능은 별도로 `system_fpr`, `system_fnr`에 기록한다.

## 3. 보정 지표

| 필드 | 정의 |
|---|---|
| `ece` | Expected Calibration Error. 구간 개수를 `n_bins`에 함께 기록한다 |
| `mce` | Maximum Calibration Error |
| `brier` | Brier score |

- ECE는 구간 개수에 따라 값이 달라지므로 `n_bins` 없이 단독 보고하지 않는다.
  기본값은 15로 하고, 보정 전후를 비교할 때 반드시 같은 값을 쓴다.
- 신뢰도 다이어그램(reliability diagram)을 `figures/`에 함께 저장한다.
  ECE 수치 하나만으로는 어느 구간에서 과신하는지 알 수 없다.

## 4. 유보 관련 지표

| 필드 | 정의 |
|---|---|
| `abstention_band` | `[lower, upper]`. 유보가 발생하는 보정 후 확률 구간 |
| `abstention_rate` | 전체 플로우 중 유보된 비율 |
| `escalation_ratio` | 실제로 심층 검증으로 전달된 비율. 보조 게이트가 없으면 `abstention_rate`와 같다 |
| `risk_coverage` | 커버리지(판정한 비율) 대비 오류율 곡선. 선택적 분류의 표준 지표 |

- `abstention_rate`와 `escalation_ratio`를 같은 값으로 가정하지 말 것.
  OOD 보조 게이트가 도입되면 달라진다.
- trade-off curve는 유보 구간 폭을 여러 값으로 스윕해 `fpr`, `fnr`, `escalation_ratio`를
  동시에 기록한 표를 산출한다. 오탐만 그리면 반쪽짜리 곡선이 된다.

## 5. 심층 검증 계층 지표 (2·3차 계층 구현 이후)

| 필드 | 정의 |
|---|---|
| `groundedness` | 제시된 근거가 검색된 근거 문서에 의해 지지되는 비율 |
| `schema_valid_rate` | LLM 출력이 지정 스키마를 만족한 비율 |
| `verification_latency_p50/p95` | 유보 플로우 1건당 검증 지연 |

- `groundedness` 판정을 같은 계열 LLM으로 수행하면 순환 논증이 된다.
  판정 주체와 산출 주체를 분리하고, 그 방법을 `metrics.json`의 `notes`에 명시한다.
- 검증 지연은 측정값만 기록한다. 목표치나 예상치를 쓰지 않는다.

## 6. 산출 형식

- 모든 수치는 `results/<EXP-ID>/metrics.json`에 기록한다.
- 소수점 반올림을 하지 않고 원값을 저장한다. 표시용 반올림은 문서 작성 시에만 한다.
- 그림은 `results/<EXP-ID>/figures/`에 PNG로 저장하고, 재생성 가능한 스크립트를 남긴다.
- 지표 정의를 바꿔야 할 경우 과거 실험 결과를 재계산하지 말고,
  새 필드명을 추가하고 이 문서에 변경 이력을 남긴다.
